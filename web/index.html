Shortcuts

Ctrl+S
Save all files
Ctrl+Shift+S
Save all files and compile
Ctrl+B / I / U
Bold / italic / underline (toolbar above the editor)
Ctrl+M
Inline math $…$
Ctrl+Shift+R
Add a reference ([1] button)
Ctrl+Shift+B
Show or hide the file tree
Ctrl+J
Show or hide the problems panel
Ctrl+O
Import a .zip project
Ctrl+Alt+O
Open a project folder in place
Ctrl+Shift+O
Open a recent project
Ctrl+W
Close the current tab
Ctrl+Tab
Next tab
Ctrl+F / Ctrl+H
Find / replace in the current file
Ctrl+Shift+F
Search and replace in the whole project
Ctrl+Alt+J
Show the cursor's line in the PDF
Double-click PDF
Jump to that place in the source
